Ladder Script adds a self-contained library (src/rung/) to Bitcoin Core plus a single boundary header (src/rung_shims.h). The patch to existing Core code is 805 lines across 29 files — routing, type definitions, build wiring. The bulk of the implementation (19,337 lines across 39 new library files) does not touch existing Core code. Per-section walkthrough: Annotated Patch and Annotated Library.

git diff v30.0..HEAD -- src/
The authoritative diff against upstream Bitcoin Core v30.0. Patched-line counts come from --numstat; modified-vs-new file split comes from git cat-file -e v30.0:<path>.
